# 人物画法与提示词

本页是人物画法的主要定义。依据四张用户截图整理，版本 v1，登记日期 2026-10-20。原图位置与观察范围见 [参考图索引](image-index.md)；图片仅提供人物视觉证据。

## 绘制目标

人物呈清楚的二维动画绘制观感：细而稳定的轮廓线，宽整有分组的发片，简洁有表演性的五官，明确的主阴影和完整高光形状，少量柔和过渡。按可见画法迁移，不推断原片使用的软件、模型或具体制作技术。

| 部位 | 应迁移的画法 | 随本次角色变化的内容 |
| --- | --- | --- |
| 线稿 | 深灰、灰紫或与局部配色协调的细轮廓，连续清楚；外轮廓和遮挡处略重，发片内部线、鼻口线更轻细；上眼线与上睫毛明显较厚，发梢线收尖 | 线色适配角色底色，线宽随景别和实际输出尺寸调整，不固定为某个像素值 |
| 脸部 | 面颊弧线柔和，下巴简洁收拢；鼻子由极少的短线或亮点表示，嘴用清楚轮廓和简单内部色块说明；面部大部分保留安静的底色面 | 保留角色身份、年龄感和主要五官关系，合理采用动画化概括；不默认改变成儿童或极端 Q 版 |
| 眼睛 | 深色上眼线形成主要重量，下缘较轻；虹膜由少量清楚的深浅色形、简洁瞳孔和完整亮点组成；表情主要由眉毛、眼睑开合与嘴形传达 | 沿用角色眼色与本次表情；蓝眼、粉色虹膜、泪珠和汗滴只在角色设计或表演需要时使用 |
| 头发 | 用宽整的弧形发片组织体积，成组分束，内部结构线有所取舍；发梢方向清楚；高光为成组的椭圆、带状或锯齿边色面，主阴影明确说明叠压 | 保留发型轮廓、长度、辫子或卷梢等原有结构；发色与染色位置按角色设定，不固定银发或蓝色渐变 |
| 皮肤 | 干净的底色配适量硬边主阴影，常见于刘海下、下颌和遮挡处；可有局部第二层阴影；面颊允许薄而局部的腮红与轻微柔和过渡 | 光向、冷暖、肤色和阴影强度由本次场景决定，不复制某张截图的整体冷蓝色罩染 |
| 衣物 | 用准确轮廓、接缝、少量主要褶线和较大的分色色面表达结构；花边、徽记、层叠和饰边保持可读，减少不服务结构的细密纹理 | 原角色服装的剪裁、图案、层数、配件数量与位置 |
| 配饰和道具 | 金属、宝石或硬质饰件用边界清楚的浅深色面与少量完整亮斑区分材质；布料仍采用有限分色 | 只绘制本次角色已有或用户要求的配饰，不自动添加王冠、宝石、手套、背包或精灵耳 |

人物必须保持线条和色面清楚。截图中的压缩软化、前景人物失焦、字幕和平台角标均不作为人物画法继承。

## 可复用画风段

以下是本版新编写的候选提示词，尚未生图验证。将其与本次角色、动作和构图合并；输入图片编号按实际传图顺序填写。

```text
人物采用“日式动漫一拍三 赛璐璐”参考中的绘画方式：细而连续的深灰或灰紫轮廓线，外轮廓与遮挡处略重，内部结构线更细，上眼线与上睫毛较厚，线条末端自然收尖。头发组织成宽整、轮廓清楚的成组发片，以少量内部弧线、明确阴影和完整高光色块说明形状。

面部轮廓柔和，鼻口用简洁的线和色形概括；虹膜采用少量清楚分层的色块、简洁瞳孔与完整亮点，保留本次角色的眼色与五官身份。平涂底色搭配清楚的赛璐璐主阴影，局部可有第二层深阴影及轻微柔和过渡，皮肤保留干净色面和适量局部腮红。衣物用准确的结构线、主要褶线与较大的分色色面表达体积，保留原有服装和配饰结构。

画风参考仅提供人物画法。人物身份、年龄感、体型、耳形、发型发色、服装配饰、动作和表情按本次设定；背景、场景与照明按本次要求。人物整体保持统一的二维动画绘制观感，轮廓、发片和衣物边界清楚。避免碎发铺满、皮肤大面积喷绘、塑料材质高光及光晕覆盖线稿。画面不继承参考截图的字幕和角标。
```

### 参考图职责句

角色图加画风图时，在完整提示词中写明实际编号，例如：

```text
图1是本次角色设计，负责身份、发型轮廓、发色眼色、体型和衣服配饰。图2是画风参考，只提取其中人物的线稿、发束、五官概括和上色方法。只改变图1人物的绘画方式，保留角色设计。图2中的人物身份、背景、服饰、表情、构图、字幕和角标不作为本次内容；本次场景与镜头按以下描述生成。
```

只有文字人物设定时，将“角色图”职责改为本次文字定义；仍可使用选中的画风截图。有多张角色图或画风图时逐张说明，不沿用与实际传图顺序不符的编号。

## 人物检查与修正

只对画面实际可见部位检查；按当前景别判断合理的细节密度。

| 检查点 | 匹配条件 | 出现偏差时优先调整 |
| --- | --- | --- |
| 线条 | 轮廓与遮挡关系清楚，内部细线有所取舍，睫毛重量与其他线条区分 | 明确细线层次与清楚边界，减少遮盖线稿的柔光；不一律把全部线条加粗 |
| 脸与眼睛 | 面部概括简洁，虹膜分层可读，角色身份与本次表情成立 | 简化虹膜微纹理和鼻口塑形，保留角色自己的脸部特征，不套用参考人物的整张脸 |
| 发片 | 发束分组完整、走向清楚，高光以有组织的色面出现 | 先重组发片和高光形状，再减少碎发；不靠抹掉全部内部线条处理 |
| 皮肤与衣物 | 底色与主要阴影分区明确，局部渐变有节制，衣饰结构保留 | 针对可见部位改成较大主阴影色形，保留接缝、图案和配件位置 |
| 多人物或多角度 | 所有可见人物、正侧背采用同一线稿和分色逻辑 | 明确指出跑偏的人物或区域，并同时保留各自身份；不只修正正脸 |
| 内容独立性 | 原角色的设计保持，本次背景与动作成立 | 清除从风格截图带入的耳形、王冠、发色、哭脸、服装、建筑或字幕等内容 |
